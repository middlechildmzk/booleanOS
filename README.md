# BooleanOS

AI sourcing query copilot for recruiters and sourcers.

## Local development

```bash
npm install
npm run dev
```

## Vercel

This app is now deployed from the repository root. Do not set a custom Root Directory in Vercel. Leave Root Directory blank.

Environment variables for first deploy:

```env
NEXT_PUBLIC_BETA_WAITLIST_MODE=true
NEXT_PUBLIC_STRIPE_ENABLED=false
```
