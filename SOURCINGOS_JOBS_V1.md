# SourcingOS Jobs V1

Jobs for people who find people.

This module adds a public recruiter career hub to BooleanOS / SourcingOS.

Core scope:

- Public jobs hub
- Recruiter and sourcer job categories
- Job detail pages
- Employer submit flow
- Admin review scaffold
- Newsletter CTA
- SourcingOS beta CTA
- SEO-first category pages

Implementation target:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Curated link-out job listings
- No login-gated scraping
- No candidate PII storage
